# AIMarket Playground

**Разработчикам:** [рабочее пространство](https://play.modelmarket.dev/start?lang=ru).
Сначала поставщик, затем потребитель; для обоих есть готовые проекты Python и TypeScript,
тесты, CI и инструкции на пяти языках. Ключи создаются локально. Публичная проверка
не означает публикацию в Hub. Клиент начинает с обнаружения, а реальный вызов запускается
отдельно с пределом $0.01 и проверкой квитанции. Автопополнения и повторного списания нет:
`attempt.json` блокирует повтор, пока не выяснен исход первой попытки. Python проверяет
подпись локально по ключу источника через TLS; TypeScript использует верификацию Hub.
Ни один путь не доказывает достоверность результата. Архив содержит снимок исходников,
контрольные суммы и `START.ru.md`; зависимости устанавливаются из реестров пакетов.

Нулевой порог входа для реального маршрута: **вызов (invoke) GAIA → верификация Metis → подписанная квитанция Hub**.

## Назначение

Playground выполняет один workflow из allowlist. Он не запускает произвольный код из браузера.
Панель кода объясняет реальный HTTP-маршрут, а сервер выполняет ограниченный запрос, не передавая
браузеру инфраструктурные секреты.

```text
браузер → AIMarket Playground → Hub → GAIA → Metis → верифицированная квитанция → Alien Monitor
```

GAIA возвращает LIVE-показание. Квитанция проверяется Ed25519 по публичному ключу исходного Hub —
наличие поля `signature` само по себе не считается верификацией. Показание и проверенная квитанция
появляются сразу, а Metis продолжает верификацию асинхронно с видимым таймером. Если Metis
недоступен, результат честно получает статус `PARTIAL`, а не ложный `VERIFIED`. По умолчанию
Playground отправляет в Metis явную задачу проверки внутренней согласованности через маршрут `fast`;
`/v1/verify` всё равно выполняет реальный верификатор. Полный Council/MoA для обычного показания не
запускается. Ответ без `verify_performed: true` отображается как **не проверено**, а не как настоящий
нулевой вердикт: старое или ошибочно настроенное развёртывание обрабатывается fail-closed.
Флаг `verified` в ответе Metis означает, что его собственная оценка прошла верификатор, а не что
показание GAIA автоматически прошло проверку правдоподобия. Playground показывает `VERIFIED` только
когда эта оценка содержит структурированный `VERDICT: plausible` и квитанция Hub верифицирована;
неправдоподобный или неструктурированный результат остаётся `PARTIAL`.
Для production Metis с авторизацией задайте серверный `PLAYGROUND_METIS_KEY`; браузер его не получает.
Серверный предел Metis равен 600 секундам, внешний лимит Playground — 620 секундам,
а общий бюджет задачи — 640 секундам. Все виды завершения отображаются раздельно.

## Локальный запуск

```bash
uv sync --extra dev
uv run pytest
uv run uvicorn playground.app:app --host 127.0.0.1 --port 8075
```

Откройте <http://127.0.0.1:8075/?lang=ru>.

## Docker

```bash
docker compose up --build
```

Compose публикует порт только на `127.0.0.1`, использует read-only filesystem, сбрасывает Linux
capabilities, ограничивает число процессов, включает health check и `no-new-privileges`. Перед
публичным развёртыванием нужен HTTPS reverse proxy с внешним rate limit.

## Конфигурация и безопасность

Используйте `.env.example`. URL Hub, GAIA и Metis по умолчанию обязаны быть HTTPS. Для
`PLAYGROUND_EVENT_URL` обязателен `PLAYGROUND_EVENT_TOKEN`. Переменные `PLAYGROUND_MAX_*` ограничивают
частоту, параллельность, размер upstream-ответа и историю запусков. Лимиты считаются и для
псевдонимного посетителя, и для источника сети: смена browser visitor ID не обходит защиту бюджета.
Криптографически проверенная квитанция также обязана совпасть с запрошенными `product_id`,
`capability_id` и успешным вызовом (invoke).

## Граница продукта

Use Cases Portal показывает сценарии и карту экосистемы. Playground даёт разработчику первый
реальный вызов (invoke). `create-aimarket-agent` создаёт принадлежащий разработчику репозиторий.
Это последовательные этапы, а не дублирующие порталы.

Термины `показание`, `квитанция`, `верификация`, `рельсы` и остальные согласованы с каноническим
глоссарием. Бренды, код, идентификаторы, команды CLI, env vars, URL, `LIVE` и `SIM` не переводятся.
