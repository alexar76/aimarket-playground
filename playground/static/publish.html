AIMarket / Hub

Publish a provider

A successful endpoint check is not Hub registration. Follow these steps on the Hub you chose; no payment or publication happens on this page.

Get an account · Check endpoint

1. Prepare the manifest

Deploy the checked endpoint over HTTPS on port 443. Keep the signing key local. Set product_id, capability_id, provider_pubkey and price_per_call_usd in capability.json; use the exact schemas and endpoint you tested.

2. Confirm publisher identity

Open the Hub account page in provider mode and create your own API key. Read account_id below and use it as publisher_id in capability.json. Keep the key in AIMARKET_API_KEY in your local terminal; never put it in the manifest or share it.

GET
curl --fail-with-body https://modelmarket.dev/ai-market/v2/account \
  -H "X-API-Key: ${AIMARKET_API_KEY:?Set your own API key locally}"

3. Read the policy and post collateral

Read /supply/policy with your key before funding: min_stake_usd is the required total, stake_usd is already posted, and additional_stake_usd is the missing amount. Check product_allowlist and admission_mode too. Top up only the shortfall beyond balance_usd on the account page, then return here. A top-up alone does not post collateral.

GET /supply/policy
curl --fail-with-body https://modelmarket.dev/ai-market/v2/supply/policy \
  -H "X-API-Key: ${AIMARKET_API_KEY:?Set your own API key locally}"

Open provider account / top up

If additional_stake_usd is zero, skip this command. Otherwise set AIMARKET_STAKE_USD to that amount and run it once. It moves spendable credit into slashable collateral; it is not a payment to your provider. Check the policy again after success. After a timeout, inspect your account and ledger before any retry: this command is not idempotent. If requires_mandate is true, the key cannot post collateral; resolve that account policy before funding. Collateral return requires the operator.

POST /supply/stake
curl --fail-with-body https://modelmarket.dev/ai-market/v2/supply/stake \
  -H "X-API-Key: ${AIMARKET_API_KEY:?Set your own API key locally}" \
  -H "Content-Type: application/json" \
  -d "{\"amount_usd\":\"${AIMARKET_STAKE_USD:?Set additional_stake_usd from policy}\"}"

4. Register explicitly

After collateral and admission requirements are met, submit the manifest from your terminal. The command changes the Hub registry. It does not invoke the provider. An API-key account can only publish under its own account_id.

POST /ai-market/v2/supply/register
curl --fail-with-body https://modelmarket.dev/ai-market/v2/supply/register \
  -H "X-API-Key: ${AIMARKET_API_KEY:?Set your own API key locally}" \
  -H "Content-Type: application/json" \
  --data-binary @capability.json

5. Verify discovery

Confirm the exact product_id, capability_id and publisher_id in the returned search results. An accepted registration is not a guarantee of discovery: trust and admission policy still apply.

GET
curl --fail-with-body --get https://modelmarket.dev/ai-market/v2/search \
  --data-urlencode "intent=YOUR_CAPABILITY_ID"

6. Resolve a refusal

400: read detail — registration may lack stake or have an invalid manifest. Re-read policy; do not top up blindly. 401/403: check the key, publisher_id, account mandate and admission verdict. 402 on /supply/stake: insufficient spendable credit; compare balance_usd with additional_stake_usd. 503: admission is unavailable; contact the operator. Do not bypass gates or repeat payments. Keep the response and check report without secrets.
